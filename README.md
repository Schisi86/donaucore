# DonauCore

**Lokale KI. Direkt auf deinem PC.** · **Local AI. Right on your PC.**

DonauCore ist eine kostenlose Windows-11-Anwendung, die KI-Sprachmodelle vollständig auf dem eigenen
Computer ausführt: Chat, Modellmanager mit kuratiertem Katalog, Projekte mit Ordnerzugriff,
eingebauter Browser und eine lokale Entwickler-API (OpenAI-, Anthropic- und Ollama-kompatibel).
Kein Konto, keine Telemetrie, keine Cloud.

DonauCore is a free Windows 11 application that runs AI language models entirely on your own
computer: chat, a model manager with a curated catalogue, projects with folder access, a built-in
browser and a local developer API (compatible with OpenAI, Anthropic and Ollama). No account, no
telemetry, no cloud.
